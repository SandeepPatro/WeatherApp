# 04 — UI

- **Search box** (top center): `rgb(255 255 255 / 0.2)` background (80% transparent), 5px radius. Autocomplete with arrow keys / Enter / Esc. 📍 button re-detects current location.
- **Weather box** (center of screen): `rgb(12 16 30 / 0.5)` background (50% transparent), 5px radius. Shows city + region, live local clock with seconds, date, condition icon, temperature, feels like, humidity, wind, cloud %, sunrise, sunset, moon phase.
- **°C / °F toggle** in the box; wind switches km/h ↔ mph. Choice saved in `localStorage`.
- Fully responsive down to 360px; details grid becomes 2 columns on phones.

## Debug URL params
Preview any scene without waiting for real weather/time:

```
?time=18:00            start the clock at 6 PM in the selected city
?weather=rain          force a condition: clear | mostlyClear | partly | overcast | fog | drizzle | rain | snow | thunder
?speed=120             run the clock 120× faster to watch transitions
```
e.g. `http://localhost:5173/?time=17:30&speed=60&weather=partly`
